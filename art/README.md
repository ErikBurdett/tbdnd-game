# Art workspace

- `source/`: original working files; normally excluded from Cursor indexing.
- `imports/<asset-id>/`: normalized tool exports plus provenance notes.
- `asset-manifest.example.json`: validated example contract.
- Runtime output belongs under `apps/client/public/assets/generated/`.

The included two-frame spearman is an original geometric placeholder. It exists to make the manifest validator executable and should be replaced before production.
