# `@ancient/game-data`

Zod schemas and cross-reference validation for data-driven factions, provinces, units, buildings, research, and historical sources.

`content/core` is deliberately tiny: it proves the content contract and supports the starter UI. Expand it to the 18–24-province vertical slice only after the first complete play loop works.

Every content record carries a classification so historical claims, gameplay abstractions, and original fantasy additions remain distinguishable.
